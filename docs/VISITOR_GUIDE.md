# Visitor guide

## Start in your browser

Open [The Living Museum](https://qsolkcb.github.io/SynergeticGames/) or a local HTTP clone. Select Museum catalogue; you do not have to play the expedition to visit an experiment. Search by title, gallery or idea. Progress counts all exhibits in the current route, not just matching search results. Open a card, manipulate its controls, read the results and reveal the explanation. Return or close at any time.

Try a short tour: Volume Exchange → Quadray Workshop → Observer Room → Hidden Tetrahedron → Homology Laboratory → Quadrature Bench. For a lesson, use the Contributor Workshop to make a route and import the route JSON. Guided order is a suggestion, not a lock.

Save exhibit exports the current experiment state. Load exhibit, route, pack or evidence accepts the relevant JSON. To restore a custom pack save, first load the identical pack. Packs and standalone states live only in the current museum page, so keep downloaded files. Research evidence is a read-only recomputation, not a save or signature. Save in the expedition toolbar is separate.

## Expedition

Begin Concentric, use W/S/A/D, arrows or touch movement; E inspects, Q switches probe, F faces partner, Space links, P/Esc pauses. Four seals and mutual visibility/facing near the engine complete the expedition. Standalone completion never grants seals. Tab reaches native controls.

Use Still exhibits for reduced motion and Economy graphics for a smaller canvas and lower rendering frequency. Fit window remains usable when fullscreen is denied. Sound is optional. Save files work if local storage is unavailable. Offline reload requires a completed service-worker installation on HTTP localhost or HTTPS. Source references may need internet.
